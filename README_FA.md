# سامانه مدیریت پروژه کارخانه

نسخه ساده‌شده بر اساس فایل `Factory_Project_Manager_Final_DashboardStable.xlsm` با معماری **React + FastAPI + SQLite**.

## قابلیت‌های پیاده‌سازی‌شده

- ثبت مشتری با الزام «شماره شروع سفارش» در اولین ثبت مشتری.
- شماره‌گذاری مستقل سفارش برای هر مشتری بر اساس پیشوند و شمارنده.
- ثبت سفارش با جدول گریدی محصولات و فیلدهای: محصول، تعداد، قیمت، نوع رنگ، رنگ، کابل، نوع/برند پروژکتور، توضیحات ویژه، **گالوانیزه** و توضیح گالوانیزه.
- نمایش و ورود تاریخ‌ها در رابط کاربری به فرمت **شمسی**؛ نگهداری داخلی تاریخ به ISO برای صحت مرتب‌سازی و گزارش.
- کنترل پروژه در سطح هر محصول با مراحل فارسی: **طراحی، خرید، تولید، QC، بسته‌بندی، تحویل، وصول**.
- صفحه مستقل خرید و تولید برای هر پروژه، با امکان ثبت یادداشت در سطح کل پروژه یا یک محصول خاص و نگهداری تاریخچه زمانی.
- پرداخت‌ها و محاسبه مانده وصول.
- ارسال جزئی در سطح محصول، محاسبه مانده ارسال، جلوگیری اولیه از ارسال با وجود بدهی و امکان ادامه پس از تأیید صریح.
- ایجاد هشدار مدیریتی هنگام ارسال با بدهی؛ هشدار تا تسویه کامل سفارش روی داشبورد می‌ماند.
- داشبورد: تعداد مشتریان دارای سفارش فعال، سفارش‌های فعال، مانده ارسال، مانده وصول، فیلتر مشتری، نمایش پروژه/محصول/مشخصات/مراحل/آخرین یادداشت، و چاپ گزارش مدیر.
- داده نمونه استخراج‌شده از اکسل: مشتری `hoshmand`، سفارش `MD11`، محصول «افرینش» و وضعیت مراحل نمونه.

## ساختار پروژه

```
factory_project_manager/
├─ backend/                 FastAPI + sqlite3
│  ├─ main.py               API و منطق تجاری
│  ├─ db.py                 Schema و اتصال SQLite
│  ├─ seed.py               داده نمونه
│  └─ e2e_check.py          تست جریان اصلی کسب‌وکار
├─ frontend/                React + Vite
│  └─ src/
│     ├─ pages/             صفحات اصلی سامانه
│     ├─ components/
│     └─ jalali.js          تبدیل تاریخ شمسی بدون وابستگی جداگانه
├─ data/factory.db          دیتابیس SQLite آماده
├─ run_windows.bat
└─ run_linux.sh
```

## اجرا در Windows

پیش‌نیاز: Python 3.11+ و Node.js 20+.

ساده‌ترین راه، اجرای `run_windows.bat` است. در اولین اجرا پکیج‌های Python و React نصب می‌شوند. سپس:

- Backend: `http://127.0.0.1:8000`
- مستندات API: `http://127.0.0.1:8000/docs`
- Frontend: `http://127.0.0.1:5173`

### اجرای دستی Backend

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r backend\requirements.txt
python -m uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000
```

### اجرای دستی Frontend

در ترمینال دوم:

```bat
cd frontend
npm install
npm run dev
```

## اجرا در Linux/macOS

```bash
chmod +x run_linux.sh
./run_linux.sh
```

یا دو بخش را مطابق دستورهای Windows (با مسیر فعال‌سازی venv لینوکسی) جداگانه اجرا کنید.

## تست منطق اصلی

از ریشه پروژه:

```bash
python -m backend.e2e_check
```

این تست به طور خودکار موارد زیر را بررسی می‌کند: شمارنده مشتری جدید، شماره سفارش، ۷ مرحله فارسی، یادداشت پروژه و محصول، جلوگیری از ارسال بدهکار، override، هشدار داشبورد، تسویه و مانده ارسال. دیتابیس اصلی قبل/بعد تست حفظ می‌شود.

## نکته دیتابیس

SQLite در فایل `data/factory.db` قرار دارد. برای پشتیبان‌گیری کافی است هنگام بسته بودن برنامه از همین فایل کپی بگیرید. برای استفاده چندکاربره سنگین در آینده می‌توان Backend را به PostgreSQL منتقل کرد بدون اینکه ساختار اصلی UI عوض شود.
